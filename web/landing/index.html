Sequence

Your cycle data stays on your device.

Sequence is a period and cycle tracker. Everything you log is written to the device you logged it on, and nowhere else. There is no account, no sync, and no server holding your records.

Open the web version Download

On-device · No account · No cloud · Free

What it does

  • Logs a day at a time — bleeding, mood, symptoms with severity, notes, and whichever other trackers you switch on.
  • Predicts the next period — from the starts you have logged, as a window rather than a single confident date.
  • Says when it doesn't know — a new install has no cycle data, so it shows none. It won't invent a cycle day to fill the space.
  • Shows patterns, not diagnoses — insights are drawn from your own logs and are not a medical opinion.

Extract and run ./sequence from inside the bundle

Only the Linux build exists so far. The others are not published because they have not been built and tested, not because they are coming shortly — each needs a machine of that kind to build on. The web version runs the same code on any device in the meantime.

The web version

period.gabrielpenman.com/app is the full app, not a preview. It stores your logs in your browser on this device, using the same storage any site gets. Clearing your browser data clears it, and it does not follow you to another browser or another machine.

It is also the test instance, so it changes without warning. For anything you want to keep, use a desktop build.

Free and open source

Sequence is free. There is nothing to buy, no subscription, and no paid tier holding features back. The source will be published so that the claim on this page — that nothing leaves your device — is something you can check rather than take on trust.
